# Atividade 01 — Laço while

Exercício dos meus estudos de Java na EBAC para praticar o laço `while` e entender como repetir instruções enquanto uma condição for verdadeira.

## O que pratiquei

- Estrutura de repetição `while`.
- Condição de continuidade do laço.
- Atualização de variáveis durante a repetição.
- Lógica básica de programação.

## Como executar

Abra o projeto no IntelliJ IDEA, confira se o JDK está configurado e execute a classe que contém o método `main()`.

## Sobre o exercício

É uma atividade curta de fundamentos, voltada para entender o funcionamento do laço na prática.

**Curso:** EBAC — Back-end Java v2
